nanoka の live 版から全キャラ/武器/リスト・アセットを取得します（重い処理あり）。

バージョンアップ

beta からのコピーは行いません。JSON（リスト含む）は nanoka live から全件取り直し、 アセットは新規追加された ID のみ取得します（既存分は基本的に変更されないため）。

その他ソース（未対応）

キャラ地域割り当て

characters.json を {地域名: [キャラ数値ID]} で管理します。1キャラを複数地域に所属させることができます。 保存内容はビルドカード生成の「地域背景」選択に使われます。 旅人（10000005/10000007）は元素ごとに背景地域が固定されるため、ここでの割り当てはできません （風→モンド / 岩→璃月 / 雷→稲妻 / 草→スメール / 水→フォンテーヌ / 炎→ナタ / 氷→スネージナヤ）。
